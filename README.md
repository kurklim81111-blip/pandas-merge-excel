# Автоматическое объединение Excel-файлов (Python + Pandas)

Скрипт для автоматизации рутинной работы с таблицами. Находит все Excel-файлы в папке по заданной маске, объединяет их в один общий файл и очищает данные от пустых значений. Идеально подходит для сведения отчетов за разные месяцы, выгрузок из разных магазинов или филиалов.

## 🛠️ Функционал:
1. **Поиск:** Автоматически находит все файлы по маске `Shop*.xlsx` в папке со скриптом.
2. **Безопасность:** Если файлы не найдены, программа не выдает ошибку, а вежливо сообщает об этом и завершает работу.
3. **Объединение:** Склеивает все найденные таблицы в одну общую (используется `pd.concat`).
4. **Очистка:** Заполняет пустые ячейки текстом «Нет данных», чтобы в отчете не было пустот.
5. **Сохранение:** Записывает итоговый результат в файл `All_shops.xlsx` без лишней колонки индексов.

## 📂 Структура проекта:
*   `main.py` — основной скрипт с логикой.
*   `Shop1.xlsx`, `Shop2.xlsx` и т.д. — примеры исходных файлов.
*   `All_shops.xlsx` — итоговый файл, который создается после запуска.
